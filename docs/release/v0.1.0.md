# v0.1.0 作品评估版

## 版本亮点

- 完成今日、日历、创建、详情和个人偏好五个核心页面。
- 支持自然语言日程解析与手动创建双路径。
- 提供时间线、准备清单、风险和个性化建议结构。
- 建立 AI、地图、通知、Store 与 Repository 的独立边界。
- 公开 APK 默认使用离线 AI Demo，不包含服务密钥。

## Android 安装

1. 从仓库 Releases 下载 `AI-Schedule-Assistant-v0.1.0.apk`。
2. 在 Android 设置中允许当前文件管理器或浏览器安装未知来源应用。
3. 安装后打开“AI Schedule Assistant”。
4. 定位与通知权限均可拒绝；核心离线 Demo 仍可使用。

## 验证

```powershell
npm.cmd test -- --runInBand
npm.cmd run typecheck
```

发布前结果：13/13 测试套件、41/41 测试用例通过，TypeScript 检查通过。

APK 完整性可使用：

```powershell
Get-FileHash AI-Schedule-Assistant-v0.1.0.apk -Algorithm SHA256
```

将输出与 Release 附带的 `SHA256SUMS.txt` 比较。

## Demo 模式说明

公开 APK 使用确定性离线 AI 响应，方便评审者无账号体验完整流程。真实模型接入由 Release 中的实机录屏展示。正式产品不会把模型密钥打包到移动端，而是通过服务端代理调用。

## 已知限制

- 仅提供 Android APK，尚未提供 iOS 安装包。
- 当前演示数据在 App 重启后重置。
- 地图在线能力在公开包中没有服务 Key。
- 这是作品评估包，并非应用商店正式版本。
